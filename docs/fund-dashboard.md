# 五基金可视化长期投资日报

这是现有五基金流程的增量报告层，沿用数据提供器、A股交易日历、通知路由和QQ SMTP，不运行浏览器脚本。普通股票模式不受影响。默认精简HTML展示近30日收益、90日净值趋势、目标配置三图，最大回撤、散点、可靠性及7/90日收益图放在本地详细版。每张图有中文解释和口径说明。

## 启用与回退

保留 Actions Variables：`STOCK_LIST=512050,563020`、`BOND_FUND_LIST=006965,007364`、`GOLD_ETF_LIST=518850`。新报告选项可不配置：

| Variable / 环境变量 | 默认 | 用途 |
| --- | --- | --- |
| FUND_REPORT_FORMAT | html | `legacy`恢复原五基金文字日报 |
| FUND_DASHBOARD_CONFIG | 空 | 可选完整JSON文件路径；Actions应使用仓库中可访问的文件，不能使用Mac路径 |
| FUND_REPORT_PERIOD | daily | `weekly`、`monthly`为近7、近30自然日观察版；不改变定时频率 |
| FUND_CHART_FONT | 自动发现 | 本地可指定中文字体文件；Actions安装Noto CJK，无需设置 |

工作日北京时间16:10首次尝试，17:10和18:10为备用触发；已成功发送当天邮件时跳过备用运行。A股交易日过滤仍由现有主入口执行；报告日期、行情交易日期、基金净值确认日期分别展示。尚未公布的当日基金净值不会被预测或填入。

沿用现有`EMAIL_SENDER`、`EMAIL_PASSWORD`（QQ SMTP授权码）、`EMAIL_RECEIVERS`等Secrets及通知策略。无需新增必填Secret，不更改现有Secrets。可选新增私有Secret **FUND_DASHBOARD_CONFIG_JSON**，内容为完整配置JSON，用于真实持仓、资金记录；读取优先级为显式文件 > 私有JSON > 默认配置。切勿将个人金额、份额、成本或授权码提交公共仓库。已有通知静默、路由和发送策略依然有效。

## 配置与个人数据

默认配置`config/fund_dashboard.json`维护名称、六位代码、资产类别、固定图色和目标权重：A50025%、红利低波15%、短债35%、政金债20%、黄金5%，对应股票40%、债券55%、黄金5%。代码映射有严格校验，不能把022430当作512050，也不能交换资产类别。

`target_pct=null`表示未配置，不补足；环形图余量为“未配置”。`history_days`支持90/180/365；有完整历史才画。`email_detail=true`可将完整六类图表放入邮件，默认false。`deviation_threshold_pp`默认5个百分点，仅用于提示。`monthly_contribution_cny=null`表示月度预算未配置。

`holdings`默认空。未来录入时须提供五只基金**同日人民币市场价值**，包括零仓位，格式如下（示意字段，不代表真实持仓）：

```json
{"022430": {"as_of": "YYYY-MM-DD", "market_value_cny": 0, "currency": "CNY"}}
```

只有五只基金全部录入且总市值大于零，才计算实际占比与相对目标偏离。金额不能为负或非有限数，币种须CNY，日期须一致且不晚于报告日。暂不计算持仓收益、组合回撤或估算当前份额。

`contributions`保存申购现金记录，各项须为非负有限金额且分基金实际金额与合计一致。字段为`date`、`planned_cny`（代码到金额）、`actual_total_cny`、`actual_by_fund_cny`。只统计报告日及之前的记录；申购现金不是当前市值，不据此输出实际资产权重。真实记录应保存在用户私有配置，而不是默认源码。

## 收益、日期与质量

- 优先获取五只实际申购场外基金的正式单位净值、累计净值、分红、拆分记录。复用现有分红再投资计算；累计净值仅展示和核对，绝不以差额作为期间收益。分红接口失败与“无分红”严格区分。007364分红异常则停用总回报、趋势与风险点，其他基金继续运行。
- 7/30/90为自然日。每幅比较图采用共同终点和共同起点（目标日前最多14日回溯），按真实日期核验交易日完整性，不插值、不向前填充。图中未包含基金均说明原因。行情超过两个A股交易日没有更新则不进入本期比较；该阈值可能排除延迟披露的基金，优先保证可信。
- 归一化指数为含分红收益序列/共同起始值×100，未复权ETF价格不混入趋势、回撤或散点。仅当联接基金历史不可用时，收益柱图允许显示明确标注的“场内ETF替代观察数据”；该数据不是场外基金实际收益，包含除息价格影响，不参与“场外表现最强/弱”解释。
- 回撤为同一区间内从历史峰值到随后低点的最大跌幅，负值展示，零回撤仍为0.00%，缺失为“暂无可靠数据”。不将短期排名或回撤作为买卖、止损指令。
- 管理人同日正式净值冲突时抑制相关净值与收益；官方无法核验显示部分缺失。正常、部分缺失、需修复、暂不可用按核心问题严重性区分，不按错误数量分类。技术异常留日志，邮件仅展示通俗原因。
- 详细版复用原ETF均线/成交量/同日折溢价、债券1年收益与回撤、信用/流动性/利率风险、黄金现货/美元/实际利率等指标；指标来源、日期、质量与调整口径独立保留。没有可靠指数估值、久期、基准财富指数或持仓时显示数据不足。
- 官方新闻检索复用现有搜索服务，只保留近7日带日期、HTTP(S)链接及官方域名的最多3条结果。无可核验事件就说明缺口，不由LLM生成新闻、情绪、评分或行情归因。新HTML流程不调用短线股票评分链路。

## 邮件兼容、产物与降级

Matplotlib在Actions生成静态PNG，Pillow压缩；不增加浏览器渲染服务。新增Matplotlib是静态中文图表所需依赖，使用现有NumPy、Pandas、Pillow。字体先检查中文字形，无法找到字体则停用图表并保留正文，不输出乱码。Ubuntu Actions/CI安装`fonts-noto-cjk`，Docker原镜像已有此字体；本地可配置字体。

邮件采用`multipart/related`，内含`multipart/alternative`的纯文本与HTML，再附`Content-ID` PNG。HTML使用表格和内联CSS，图片宽度100%且最大640像素、具有替代文字。无外链图床、无JS；原始PNG总量上限2MB，单图失败/超限仅影响该图。通知只调用一次合并发送；SMTP失败不会再走旧版重发。整体准备失败才恢复原版报告。其他既有通知渠道继续接收文字。

报告保存`reports/fund_dashboard_YYYYMMDD_daily.{md,html,eml}`、`*_details.html`及同名PNG目录；HTML为内嵌data URI的离线浏览版，EML才是邮件实际CID版。仍被原Actions Artifacts与历史目录收集，不删除旧日报。新HTML模式不生成原股票LLM交易评分或其数据库分析记录；已有历史保留。未配置债券与黄金列表时走原股票流程。

QQ SSL465连接和发送方法沿用现有EmailSender；自动化验证MIME结构、CID匹配、纯文本回退及单次发送。**未向真实QQ邮箱发送测试邮件，也未实际验收QQ网页版、手机及桌面客户端呈现**。本地HTML预览不能替代真实邮件客户端验收。Linux字体安装及云端定时运行需合入后由Actions确认。


Demo净值是确定性的合成历史测试数据，最新样本日2026-10-16，演示报告日2026-10-20，页面明确标注。没有将历史样本当实时行情，也不会调用网络或SMTP。可用`--config`传入私有配置查看资金记录。

周/月观察入口已预留；自然周/月结算、持仓收益、完整定投执行计划与历史数据质量变化仍待相应数据接入，不伪造。未改英文README：功能面向人民币基金中文邮件，专题文档集中说明，原API/Web/Desktop载荷不变。桌面打包未验证；如未包含新配置或字体会回退原版，GitHub Actions为本次主要支持环境。
